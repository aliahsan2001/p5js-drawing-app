# P5.js Drawing App

**Portfolio focus:** event-driven canvas interaction and a modular tool architecture.

**Start reviewing here:** [`js/toolbox.js`](./js/toolbox.js), [`js/sketch.js`](./js/sketch.js), and the individual tools in [`js/tools/`](./js/tools/).

A browser drawing application built with JavaScript and p5.js. It includes multiple drawing tools, image/stamp tools, color controls, and a toolbox-based interface.

## Tech Stack

- JavaScript
- p5.js
- HTML
- CSS

## Features

- Freehand drawing
- Line, eraser, mirror, spray, stamp, rotate, image, and selection tools
- Color palette controls
- Modular JavaScript tool files
- Asset-based toolbar icons

## How to Run

Serve the repository root with a local HTTP server so assets load consistently. For example, with Python installed:

```bash
python -m http.server 8000
```

Then open **http://localhost:8000**. The VS Code Live Server extension is another option.
